# Classification-with-Naive-Bayse

A collection of machine learning projects implementing     Naive Bayes     algorithms for classification and recommendation tasks. This repository includes practical applications ranging from medical diagnosis to movie recommendation systems.

   📂 Projects Overview

    1. 🏥 Heart Disease Classification
Predicting the presence of heart disease using the     UCI Heart Disease Dataset    .

-     File    : `Heart_Disease_Classification_with_Naive_Bayse.ipynb`
-     Dataset    : `Heart-Disease-UCI.csv`
-     Algorithm    : Gaussian Naive Bayes
-     Goal    : Build a probabilistic model to classify patients based on various medical attributes (age, sex, chest pain type, blood pressure, cholesterol, etc.)

    2. 🎬 Movie Genre Suggestor
A classification system that suggests movie genres based on user preferences and movie features.

-     Files    : 
  - `Movie_Genre_Suggestor_with_Naive_Bayes.ipynb`
  - `Movie_Genre_Suggestor_with_Naive_Bayes.py`
-     Algorithm    : Multinomial Naive Bayes
-     Goal    : Classify and suggest appropriate movie genres based on input features

    3. 🍿 Movie Recommender System
A recommendation engine that suggests movies to users based on their ratings and preferences.

-     Files    :
  - `Movie_Suggestor_with_Naive_Bayse.ipynb`
  - `Movie_Suggestor_with_Naive_Bayse.py`
-     Datasets    : 
  - `movies.csv` (Movie metadata)
  - `ratings.csv` (User ratings)
-     Algorithm    : Naive Bayes for collaborative filtering
-     Goal    : Recommend movies to users based on their historical ratings
